# L'Alpiniste

Ce projet présente le jeu de société collaboratif et compétitif "L'Alpiniste", une course de montée en montagne où chaque joueur cherche à faire grimper son personnage jusqu'au sommet avant les autres.

## Objectif du jeu

- Nombre de joueurs : maximum 3
- But : être le premier à faire monter son personnage jusqu'au sommet de la montagne.
- Les joueurs doivent relever des épreuves de dextérité, d'adresse et d'intelligence.
- Les personnages ne peuvent pas descendre en dessous du cran zéro.
- Les crans peuvent être délimités par des marques sur la table, à l'aide de craie ou de post-it, selon l'appréciation des joueurs.

## Matériel

- Une table utilisée comme support principal
- Des poulies fixées au rebord de la table avec des vis
- Une pioche de cartes épreuves
- 16 cartons de jeu (rapport 2:3)
- Huit paires de montages différentes avec leur nom, altitude et coordonnées géographiques
- Un minuteur pour mesurer la durée des épreuves
- Une cloche ou système sonore pour signaler la fin du temps

## Déroulement d'une épreuve

À chaque tour, les joueurs, en commençant par le plus jeune, piochent une carte épreuve.

Chaque épreuve se joue selon les règles suivantes :

- Un joueur déclenche manuellement le minuteur au début du défi.
- La durée est choisie selon le type d'épreuve.
- Lorsque le temps est écoulé, la cloche s'arrête et toutes les actions doivent immédiatement cesser.

Les points gagnés lors des épreuves permettent de faire monter les personnages de plusieurs crans.

## Les épreuves

### 1. Test d'adresse : Le lancé de cartons

Un joueur sert de cible en tenant la boîte de jeu à quatre pas d'une ligne imaginaire. Les autres joueurs sont les tireurs.

- Chaque tireur dispose de 4 cartons.
- Dans le temps imparti, ils lancent chacun leur tour pour faire atterrir leurs cartons dans la boîte.

Compter les points :
- Le nombre de points gagnés dépend directement du nombre de cartons rentrés dans la boîte avant la fin du délai.

### 2. Test d'intelligence : Memory

- Les cartons sont disposés faces cachées sur la table en matrice 4x4.
- Les joueurs jouent à tour de rôle.
- Pendant le temps imparti, ils retournent deux cartons à la fois pour retrouver des paires identiques.

Compter les points :
- Chaque paire retrouvée avant la fin du temps donne un point à tous les joueurs.

### 3. Test de dextérité : La pyramide / Le château de cartons

Les joueurs doivent utiliser les 16 cartons de jeu pour construire un château ou une pyramide stable à l'intérieur de la boîte ou sur la table avant que la cloche ne sonne.

Compter les points :
- Si la structure tient debout à la fin du chrono, les trois joueurs gagnent 5 points.
- Si la structure s'écroule, les joueurs descendent tous de 5 crans.

### 4. Test physique

- Placer un carton sur la tête.
- Se lever.
- Faire trois tours de la table.
- Se rasseoir sans faire tomber le carton.

Compter les points :
- Réussir les trois tours rapporte 1 point.
- Faire tomber le carton fait descendre le joueur de 2 crans.

### 5. Test d'équilibre

- Poser un carton en bord de table.
- Lui donner un coup par en dessous.
- Le rattraper avec la même main en vol.

## Victoire

Le ou les joueurs qui réussissent à faire monter leur personnage jusqu'au dernier cran en haut du dispositif remportent la partie.
